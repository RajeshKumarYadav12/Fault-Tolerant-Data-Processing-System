STEP 3: Check duplicate
  ├─ fingerprintIndex.has("abc123...")
  └─ Not found → proceed

STEP 4: Store
  ├─ processedEvents.set(id, eventData)
  └─ fingerprintIndex.set("abc123...", id)

  └─ Fingerprint: "abc123..." (SAME!)

  └─ Return: { success: false, was_duplicate: true }

  └─ Event stored once, client retried safely!
